# Buimo Road Early Learning Phonics School (BRELPS) Website

## Project Overview
This project represents the final integrated web design solution (Assessment 4) for **Buimo Road Early Learning Phonics School**, located in Lae, Morobe Province, Papua New Guinea. The website builds directly upon the semantic HTML5 structure of Assessment 2 and the responsive CSS3 styling of Assessment 3, now fully integrated with dynamic JavaScript features, enhanced form handling, and comprehensive testing.

## Features & Requirements Met
* **Semantic HTML5:** Clean structural tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **External Stylesheet:** Organized, reusable CSS (`style.css`).
* **Flexbox & CSS Grid:** 
  * Flexbox is used for navigation alignment, card layouts, and header elements.
  * CSS Grid is implemented for the two-dimensional layout structure (`.grid-container`)
**JavaScript Interactivity:** Implements two meaningful features supporting user needs:
  * Interactive table filtering for school programs and fees on `services.html`.
  * Dynamic client-side form validation and interactive success alerts on `contact.html`.
* **Responsive Web Design:** Fully adapts to **Mobile** (~320–480px), **Tablet** (~600–900px), and **Desktop** viewports using media queries and flexible units.
* **Accessibility:** Includes visible focus states and accessible contrast for interactive elements.
* **Interactive Forms & Tables:** Fully validated contact/inquiry forms with fieldsets and clear data tables for school fees and programs.

## File Structure
* `index.html` - Home page featuring school introduction and educational levels.
* `services.html` - Information and services page including program fees in tabular format.
* `contact.html` - Registration and inquiry page containing an accessible HTML form.
* `style.css` - Custom stylesheet handling global rules, layouts, media queries and UI components.
* `script.js` - JavaScript file handling interactive program filtering and form validation logic.
* `logo-mark.jpeg` - Official school logo and media assets.
